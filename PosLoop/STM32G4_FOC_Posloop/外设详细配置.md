12位分辨率
    
    12位在速度、精度和代码处理复杂度之间比较均衡。

扫描模式  

    因为ADC1注入组需要按照Rank依次转换两个通道：Ia、Ic。

关闭连续转换  

    电流采样必须和PWM同步，所以不能让ADC自己不停地采。

数据溢出时保留旧数据 

    如果上一次结果还没有读取，新结果又到来，保留旧结果并置位溢出标志。
    正常情况下，FOC必须及时读取，不能长期发生Overrun。


关闭硬件过采样  

    过采样可以降低噪声，但会增加转换时间。电流环优先保证转换速度，因此没有开启。

//////////////////////////////////////////// TIM1 ////////////////////////////////////////////

TIM1时钟来源为170 MHz
        ↓
预分频器PSC = 0
（Prescaler = 1-1，因此计数器不分频）
        ↓
设置中心对齐计数模式
CounterMode = CENTERALIGNED1

计数器运行过程：
0 → 8499 → 0 → 8499 → 0
        ↓
自动重装载值ARR = 8499
        ↓
得到中心对齐PWM频率：

fpwm = 170 MHz ÷ [2 × (8499+1)]
     = 10 kHz

PWM周期Tpwm = 100 μs
        ↓
配置CH1、CH2、CH3为PWM1模式
初始CCR1 = CCR2 = CCR3 = 0
（上电时不直接输出有效占空比）
        ↓
FOC计算得到三相占空比tABC
        ↓
将占空比写入比较寄存器：

TIM1_CCR1 = tABC[0] → A相
TIM1_CCR2 = tABC[1] → B相
TIM1_CCR3 = tABC[2] → C相
        ↓
CCR与CNT不断进行比较
（CCR决定对应桥臂的PWM占空比）

占空比近似为：

Da = CCR1 / 8500
Db = CCR2 / 8500
Dc = CCR3 / 8500
        ↓
CCR预装载功能使新占空比先写入影子寄存器
（避免在PWM周期中途修改导致输出脉冲突变）(相当于抽水机加了一个蓄水箱)
        ↓
到达TIM1更新事件时
新CCR统一装入实际比较寄存器
        ↓
下一PWM周期使用新的三相占空比


配置CH4为PWM2模式,用来触发电流采样
CH1～CH3采用PWM模式1(下降沿)是为了根据CCR正常生成三相驱动占空比(有效电平)，而CH4采用PWM模式2(上升沿触发)是为了让其上升沿出现在载波波峰附近，从而避开开关噪声并触发ADC采样。

消隐有效:
    C相上管导通
    → 低侧采样无效

    → 低侧采样有效
    → COMP1正常进行过流保护
